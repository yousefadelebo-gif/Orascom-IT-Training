## 📚 What I Learned

### 1. Networking Fundamentals
- Network components and basic networking concepts
- LAN, WAN, WLAN, PAN, and MAN
- Network topologies and network types
- Client-server and peer-to-peer concepts

### 2. OSI Model & Network Protocols
- The seven layers of the OSI model
- TCP/IP model and protocol mapping
- Encapsulation and Protocol Data Units (PDUs)
- TCP vs. UDP
- Common network protocols and their purposes

### 3. Ports & Services
- Common TCP and UDP ports
- HTTP and HTTPS
- SSH, SFTP, RDP, and SNMP
- DNS and other essential network services

### 4. Network Media & Cabling
- UTP and STP copper cabling
- Single-mode and multimode fiber
- Ethernet cables and categories
- RJ-45, RJ-11, and fiber connectors
- Patch panels, transceivers, and cable standards

### 5. Network Devices & Switching
- Switches, routers, hubs, and firewalls
- Collision domains and broadcast domains
- VLANs and trunk ports
- MAC address tables
- PoE, MIMO, and wireless networking concepts

### 6. IP Addressing & Subnetting
- IPv4 and IPv6 addressing
- Public and private IP addresses
- Network and broadcast addresses
- Subnet masks and CIDR notation
- Subnet block sizes and usable host calculations
- Default gateways and static IP configuration

### 7. Wireless Networking
- Wireless standards and communication technologies
- Infrastructure and ad hoc modes
- NFC, Z-Wave, and ANT+
- Wireless channels, security, and connectivity concepts

### 8. Routing
- Routing tables and packet forwarding
- Directly connected and remote networks
- Static and dynamic routing
- Routing metrics and path selection
- Load balancing
- RIP, EIGRP, OSPF, and BGP as covered in the training material

### 9. Network Security
- The CIA Triad: Confidentiality, Integrity, and Availability
- Symmetric and asymmetric encryption
- Hashing and integrity verification
- MITM, DoS, DDoS, phishing, ransomware, and session hijacking
- VLAN hopping and insider threats
- Security controls, patching, and vulnerability scanning
- MFA, Acceptable Use Policies, and security awareness

### 10. Cloud Computing & Virtualization
- SaaS, PaaS, and IaaS
- Public and private cloud concepts
- Hypervisors and virtual machines
- Cloud computing benefits and security considerations

### 11. Network Troubleshooting Tools & CLI
- Cable testers, certifiers, crimpers, and punch-down tools
- Multimeters, loopback plugs, and toner probes
- TDR/OTDR and cable fault detection
- Protocol and wireless analyzers
- `ping`, `tracert`, `ipconfig`, `arp`, `netstat`, `nslookup`, and `route`
- Linux/UNIX equivalents, including `ifconfig` and `traceroute`
- Basic connectivity diagnosis and network troubleshooting
